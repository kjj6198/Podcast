## 大綱

身為軟體工程師當然要從第 0 集開始！這集聊聊我們的失敗故事，希望能帶給大家一些啟發。

Mooly 分享了他在新加坡工作時，因為語言的理解錯誤，導致同事被誤會，實力被低估的情況，以及他在學習日文時，因為語言不通的關係導致生活上的一些不方便；Kalan 則是分享了他在實習時因為自己犯的錯誤導致程式碼差點洩漏出去，以及家庭因素、成長環境所造成的自卑。
或許在一些人眼中，這些失敗微不足道，但我們聊完發現比較失敗是沒有意義的。不過失敗可以被複製，就像把 SSH 私鑰上傳到公開的網路上一樣。

## 補充

- 故事中裡提到的 SSH 私鑰，可以想像成是家裡鑰匙，把 SSH 私鑰上傳到公開的網路上等於把鑰匙丟在路上，任何人拿到這把鑰匙都可以打開家門。
